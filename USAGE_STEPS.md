# How to use (very simple, step-by-step)

1. Clone the repo to your computer:
   git clone https://github.com/homlander2cool/indigio-prototype.git
2. Switch to the branch with the redesign:
   git checkout feature/rbc-redesign-visuals
3. Open PowerShell in the repo folder.
4. Install dependencies:
   npm install
5. Start the site locally:
   npm run dev
6. Open your browser to http://localhost:3000 to view the site.

If you want a preview on Vercel, go to vercel.com, import the repo, and deploy.
