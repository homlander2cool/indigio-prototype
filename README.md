# RBC site prototype — visual redesign

This branch contains the visual redesign changes for the RBC prototype:
- Brand colors and typography
- Hero with dark-blue overlay and accessible white headline
- CTA styles, cards, and spacing refinements
- Simple SVG logo (placeholder) in public/

This branch intentionally does NOT include scraped site output.

Quick start (like a 5 year old)
1. Install Node.js (ask a grown-up if you need to). Go to https://nodejs.org and click LTS.
2. Open PowerShell in this folder (the repo root).
3. Type: `npm install` and press Enter. Wait until it finishes.
4. Type: `npm run dev` and press Enter.
5. Open your browser and go to http://localhost:3000 — see the site live!

To make a preview on Vercel (super easy):
1. Sign in at https://vercel.com and click "Import Project".
2. Pick this GitHub repo and accept default settings.
3. When it builds, Vercel gives you a preview URL. That's it.
